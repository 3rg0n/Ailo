================================================================================
RECOMMENDATIONS BY USE CASE
================================================================================

When to use each style:

  ZERO-SHOT (Plain English):
    - Premium/advanced models (Claude, GPT-4)
    - Simple, straightforward tasks
    - When token cost is a concern
    - When speed is critical

  SCHEMA (Structured Prompts):
    - Budget/smaller models
    - Tasks requiring specific output format
    - When persona/context matters
    - Complex multi-constraint tasks

  CHAIN-OF-THOUGHT:
    - Mathematical/logical reasoning
    - Multi-step problem solving
    - When accuracy > token efficiency
    - Complex analysis tasks
